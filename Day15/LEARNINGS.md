# Day 15 — Learnings

## What I Learned

During Day 15, I learned the fundamentals of Large Language Models and how they can be integrated into Python applications.

### 1. Large Language Models

I learned that LLMs are AI models trained on large amounts of text data. They can understand and generate human-like language.

### 2. Transformer Architecture

I learned that modern LLMs are largely based on Transformer architectures.

The Transformer uses attention mechanisms to identify relationships between different tokens in a sequence.

### 3. Attention Mechanism

Attention allows the model to focus on relevant parts of the input when generating an output.

This helps the model understand relationships between words and concepts.

### 4. Pre-training and Fine-tuning

I learned the difference between:

- **Pre-training:** Learning general language patterns from large datasets.
- **Fine-tuning:** Further training a model for a specific task or domain.

### 5. Tokens

I learned that LLMs process text as tokens. Tokens can represent complete words, parts of words, punctuation, or other text units.

### 6. Context Window

The context window represents the amount of information a model can process during an interaction.

A larger context window allows the model to work with longer conversations and documents.

### 7. Temperature

I learned that temperature affects the randomness of generated responses.

- Lower temperature → more predictable output
- Medium temperature → balanced output
- Higher temperature → more varied and creative output

### 8. Top-p

I learned that `top_p` controls probability-based token sampling.

A lower value generally produces more focused responses, while a higher value can allow more diversity.

### 9. Output Limits

I learned that output-token limits can control the maximum amount of text generated by an LLM.

A smaller limit may cause the response to end earlier.

### 10. LLM Use Cases

LLMs can be used for:

- Text generation
- Summarization
- Classification
- Question answering
- Code generation
- Translation
- Chatbots
- Content generation

### 11. LLM Limitations

I learned that LLMs can have several limitations:

- Hallucinations
- Knowledge limitations
- Context limitations
- Reasoning errors
- Bias
- Dependence on prompt quality

Therefore, important AI-generated information should be verified.

## Security Learning

One of the most important lessons was API key security.

API keys should:

- Be stored in environment variables
- Be kept inside `.env`
- Be added to `.gitignore`
- Never be committed to GitHub
- Never be shared publicly
