# Day 2 Learnings – Python Data Types and Variables

## 1. Python Data Types

During Day 2, I learned about the basic Python data types:

* `int` is used for whole numbers.
* `float` is used for decimal numbers.
* `bool` represents `True` or `False`.
* `str` is used for text and characters.

The `type()` function can be used to check the data type of
a variable at runtime.

## 2. Type Conversion

I learned that Python allows values to be converted between
different data types.

Examples include:

* Integer to string using `str()`
* String to float using `float()`
* Float to integer using `int()`

When a float is converted to an integer, the decimal part is
removed.

## 3. Interactive Programs

I learned how to use the `input()` function to create
interactive Python programs.

User input is initially received as a string, so it must be
converted to an appropriate numeric type before performing
mathematical calculations.

I also learned how to use `try-except` for handling invalid
user input.

## 4. Python Memory Management

From the research task, I learned that Python manages memory
automatically. Variables refer to objects stored in memory,
and Python handles memory allocation and deallocation.

Reference counting and garbage collection help Python manage
objects that are no longer required.

## 5. Mutable and Immutable Types

Mutable objects can be changed after they are created.
Examples include lists and dictionaries.

Immutable objects cannot be changed after they are created.
Examples include integers, floats, strings, and tuples.

Understanding mutability helps prevent unexpected changes
when working with Python objects.

## 6. Variable Naming and PEP 8

I learned that Python variable names should be meaningful
and descriptive.

PEP 8 recommends using `lowercase_with_underscores`
(snake_case) for variable names.

For example:

```python
first_number = 5
second_number = 3
```

Meaningful names make code easier to read and maintain.
