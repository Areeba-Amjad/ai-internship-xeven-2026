## Machine Learning Concepts

Today I learned about three major types of Machine Learning:

### 1. Supervised Learning

Supervised Learning uses labeled data. The model learns from input features and their correct outputs to make predictions on new data.

### 2. Unsupervised Learning

Unsupervised Learning uses unlabeled data. The model identifies hidden patterns, groups, or relationships without predefined output labels.

### 3. Reinforcement Learning

Reinforcement Learning is based on interaction between an agent and an environment. The agent learns through actions, rewards, and penalties.

## Decision Trees

I learned that a Decision Tree makes decisions by following a sequence of conditions. Each condition acts like a decision node, while the final result represents a leaf node.

In the loan approval simulator, age, income, and credit score were used as decision conditions.
