# Day 9 Learnings: Tuples & Sets

## Tuples

- Learned that tuples are ordered and immutable collections.
- Learned how to create tuples and access their elements.
- Learned that tuple values cannot be modified after creation.
- Used tuples to store city names and geographic coordinates.
- Learned how to calculate distance between coordinates.

## Sets

- Learned that sets store unique values.
- Learned that sets automatically remove duplicate values.
- Learned set operations:
  - Union
  - Intersection
  - Difference
- Used sets to track unique website visitors.
- Calculated visitor growth and retention rates.

## Email Validation

- Learned how to use sets to store valid email domains.
- Validated email addresses using the `@` symbol and domain.
- Used sets to prevent duplicate email registrations.
- Used set operations to find emails from specific domains.

## Key Takeaways

- Tuples are useful for fixed data.
- Sets are useful for unique data.
- Set operations are useful for comparing and combining data.
