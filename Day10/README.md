# Day 10: Dictionaries & JSON

## Overview

Day 10 focused on Python dictionaries and JSON data handling. The practical
session covered how dictionaries store data using key-value pairs, how to
work with nested dictionaries, and how JSON can be used for data persistence.

## Topics Covered

- Dictionaries and key-value pairs
- Dictionary lookup and mutability
- Dictionary methods
- Nested dictionaries
- JSON format
- `json.load()`
- `json.dump()`
- Dictionary comprehensions

## Practical Tasks

### Task 1: Student Information System

Built a student management system using nested dictionaries.

Features implemented:

- Add students
- Update student grades
- Calculate student average
- Find top-performing student
- Save student data to JSON
- Load student data from JSON
- Generate a sorted student performance report

### Task 2: Product Inventory Manager

Built an inventory management system using dictionaries.

Features implemented:

- Add products
- Update stock
- Search products by category
- Generate low-stock alerts
- Calculate total inventory value
- Calculate average product price by category
- Export inventory data to JSON

### Task 3: Configuration Manager

Built a configuration management system using JSON.

Features implemented:

- Create configuration JSON file
- Load configuration
- Validate required keys
- Provide default values
- Handle missing keys using `.get()`
- Update configuration programmatically
- Save updated configuration
