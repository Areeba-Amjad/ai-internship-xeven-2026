# Day 14: Learnings

## What I Learned

Today I reviewed the main Python data structures and learned how to choose the appropriate structure depending on the problem.

### 1. Lists

I learned that lists are ordered and mutable collections. They are useful when data needs to be changed, added, or removed.

### 2. Tuples

I learned that tuples are ordered but immutable. They are useful for storing fixed data that should not be modified.

### 3. Sets

I learned that sets store unique values and automatically remove duplicates. Sets are useful for membership testing and operations such as union and intersection.

### 4. Dictionaries

I learned that dictionaries store data using key-value pairs. They are useful when information needs to be accessed using meaningful keys.

### 5. Time Complexity

I learned the basic time complexity of common operations for lists, tuples, sets, and dictionaries. Understanding Big-O helps in selecting efficient data structures.

### 6. Nested Data Structures

The Contact Management System helped me understand how different data structures can be combined.

For example:

* Dictionary for contacts
* Dictionary for individual contact information
* Set for tags
* List for notes

### 7. Dictionary Comprehensions

I practiced dictionary comprehensions for searching and filtering contacts efficiently.

### 8. Set Operations

I used sets for contact tags and learned how they can prevent duplicate tags and make tag management easier.

### 9. JSON

I learned how to save Python data into a JSON file and load it back into the program.

I also learned that Python sets are not directly JSON serializable, so tags need to be converted from a set to a list before saving.

### 10. Exception Handling

I practiced handling errors such as:

* Missing JSON files
* Invalid JSON data
* Invalid contact data
* File operation errors

### 11. Functions

I learned how breaking a large program into smaller functions makes the code easier to understand, test, and maintain.

### 12. Interactive CLI

I learned how to create a menu-driven program using a `while` loop and conditional statements.

## Challenges Faced

One challenge was understanding how different data structures work together inside a nested dictionary.

Another challenge was handling JSON conversion because JSON does not directly support Python sets.

I also learned that functions must be executed or defined before they are called when working interactively in a Jupyter Notebook.

## Key Takeaway

The biggest takeaway from Day 14 is that choosing the right data structure can make a program more organized, efficient, and easier to maintain.

The Contact Management System gave me practical experience combining lists, tuples, sets, dictionaries, functions, comprehensions, JSON, exception handling, and loops into one project.
