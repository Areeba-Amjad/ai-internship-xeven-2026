
# Text Embeddings & Semantic Search

## Overview

This project explores text embeddings, cosine similarity, semantic
search, and document similarity using Python and Sentence Transformers.

The project demonstrates how text can be converted into numerical
vectors and compared based on semantic meaning rather than simple
keyword matching.

---

## Objectives

The main objectives of this project were:

- Understand text embeddings.
- Generate embeddings for sentences and documents.
- Implement cosine similarity from scratch.
- Compare semantically similar and different sentences.
- Build a simple semantic search system.
- Find similar documents.
- Detect near-duplicate documents.
- Visualize document embeddings in 2D.
