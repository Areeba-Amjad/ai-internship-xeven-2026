# Day 12: Functions in Python

## Overview

Day 12 focused on Python functions and their practical implementation.

The main concepts covered were function definitions, arguments, variable scope, and function design principles.

## Topics Covered

- Function definition using `def`
- Parameters and return values
- `None` return
- Positional arguments
- Keyword arguments
- Default parameters
- Argument unpacking
- Local and global scope
- `global` keyword
- Variable lifetime
- Single Responsibility Principle
- Descriptive function names
- Docstrings

## Practical Tasks

### Task 1: Math Utility Library

Implemented:

- `calculate_average()`
- `find_median()`
- `get_standard_deviation()`

The functions include validation for empty lists and non-numeric values. Default parameters were also used for rounding precision.

### Task 2: Text Processing Functions

Implemented:

- `count_words()`
- `extract_emails()`
- `remove_punctuation()`
- `title_case()`
- `process_text()`

The `process_text()` function demonstrates function chaining and default parameters. Multiple values are returned using tuples.

### Task 3: Validation Function Suite

Implemented:

- `validate_email()`
- `validate_phone()`
- `validate_date()`
- `validate_password()`
- `validate_user_input()`

Each validator returns an `(is_valid, error_message)` tuple.
