# Day 11: Loops & Iteration

## Overview

Day 11 focused on Python loops and iteration. The session covered
`for` loops, `while` loops, loop-control statements, nested loops,
and practical applications of iteration.

## Topics Covered

### 1. For Loops

- Iterating over sequences
- `range()`
- `enumerate()`
- `zip()`

### 2. While Loops

- Condition-based iteration
- Infinite loops
- Loop termination
- Loop control

### 3. Break, Continue & Else

- `break`
- `continue`
- `else` with loops
- Controlling loop flow

### 4. Nested Loops

- Nested iteration
- Matrix operations
- 2D data processing
- Pattern generation
- O(n²) time complexity

## Practical Tasks

### Task 1: Data Processing Pipeline

Implemented a data processing pipeline that:

- Processes 1000 records
- Uses `for` loops
- Uses `enumerate()` to track progress
- Uses `continue` to skip invalid records
- Uses `break` for critical errors
- Uses `zip()` to combine data sources
- Validates matching data-source lengths

### Task 2: Pattern Generators

Implemented:

- Multiplication tables
- Pyramid patterns
- Number triangles
- Matrix transpose
- Row and column sums
- Diagonal element extraction
- ASCII art

### Task 3: Number Analysis System

Implemented:

- Prime number detection
- Optimized prime checking
- Factorial calculation
- Fibonacci sequence
- Number guessing game
- Attempt limits
- Guessing hints
