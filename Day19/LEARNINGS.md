
# Day 19: Learnings

## Prompt Engineering

Prompt engineering is the process of designing effective instructions for Large Language Models.

A well-designed prompt can control:

- Model behavior
- Task requirements
- Context
- Output format
- Constraints
- Examples

---

## Zero-Shot Prompting

Zero-shot prompting performs a task without providing examples.

### Example

```text
Classify this review as Positive, Negative, or Neutral.
